# Roshni story page

A cinematic scroll page that tells Roshni's story and links to the live demo.
Live address after merge: https://macvxace.github.io/roshni/story/

- One self-contained file (`index.html`): no libraries, fonts or outside requests.
- Uses the example photos already in `web/examples/` (DeepDRiD, CC BY-SA 4.0).
- Does **not** change anything in `web/`, the tests, the model or the video.
- Every number comes from the frozen evaluation in this repository.

Check it (optional): `pip install playwright && python3 -m playwright install chromium && python3 story/check_story.py`
